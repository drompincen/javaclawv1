WHY logs in MongoDB? Centralized logging to MongoDB enables correlation with sessions and events. A single query can show all activity for a session — logs, events, and messages together. No need to cross-reference separate log files.
WHY not just file logs? File logs require SSH access and grep. MongoDB logs are queryable via REST API and visible in the cockpit UI. Filter by level, source, session, or time range — all from the browser.
