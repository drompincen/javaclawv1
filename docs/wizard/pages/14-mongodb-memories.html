14 MongoDB: memories collection

Scoped knowledge with TTL expiry — agents learn and forget

memoriesTTL indexes
Scoped knowledge base. 4 scopes with different TTLs. Full-text searchable. Agents save analysis summaries; downstream agents load as context.
memoryIdscopeprojectIdsessionIdthreadIdkeycontenttags[]expiresAt
Read: All agents (context building), MemoryTool (recall), ContextCommandService
Write: MemoryTool (save), DistillerService (compress), agents (learned facts)
Compounds: {scope,key}, {projectId,scope}, {threadId,scope} • TTL: expiresAt
WHY scoped memory? Prevents context explosion. Without scoping, every agent would load every memory for every project. The 4-scope hierarchy mirrors organizational boundaries — global facts vs. project-specific vs. session-transient.
WHY TTL? Stale memories cause hallucination. A 30-day-old sprint analysis is misleading in week 8. TTL auto-cleanup ensures agents reason over fresh data without manual maintenance.
