4 The Intake Pipeline

7 phases: raw paste → structured intelligence

0
Memory-First Ingest ALWAYS
Raw content saved as PROJECT-scoped memory with 7-day TTL
1
Triage intake-triage
LLM classifies: THREAD yes/no | TICKETS yes/no | PLAN yes/no | RESOURCES yes/no
2
Generalist Hydration ALWAYS
Creates threads, tickets, resources in a single burst of tool calls
3-4
Tickets & Plan CONDITIONAL
PM creates tickets (Jira keys preserved). Plan agent creates phases + milestones.
5
Objective Synthesis CONDITIONAL
Derives sprint objectives from threads + tickets. Computes coverage %.
6
Reconciliation CONDITIONAL
Detects: MISSING_EPIC, DATE_DRIFT, OWNER_MISMATCH, SCOPE_MISMATCH
7
Resource Analysis CONDITIONAL
Maps people → tickets → objectives. Computes capacity, detects overload.
