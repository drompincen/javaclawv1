How the UI Token Counter Works

The cockpit footer shows 🪙 0 tokens | 0 calls | avg 0ms. This reads from llm_interactions via REST API. LlmUsageTracker aggregates per-session totals. Every LLM call (real or mocked) is recorded, enabling cost estimation per project, per agent, and per execution.
