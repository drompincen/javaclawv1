20 Quick Start

Get JavaClaw running in 3 steps

# Step 1: Start MongoDB
$ docker compose up -d mongodb
# Step 2: Set API key
$ export ANTHROPIC_API_KEY=sk-ant-...
# Step 3: Launch
$ jbang javaclaw.java --headless
# Open http://localhost:8080
Prerequisites
✓ Java 21+ • ✓ Docker • ✓ JBang
✓ ANTHROPIC_API_KEY or OPENAI_API_KEY
Key CLI Flags
--headlessREST gateway only
--testmodeMock LLM (no API key)
--scenario <file>Run E2E scenario
--port <n>HTTP port (default: 8080)
