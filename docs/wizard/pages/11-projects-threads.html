11 MongoDB: projects & threads

Project containers and long-form knowledge threads

projectsroot aggregate
Top-level organizational container. Groups threads, things, memories, and agent schedules. Status: ACTIVE or ARCHIVED.
projectIdnamedescriptionstatustags[]metadata{}
Read: All controllers (scope filtering), IntakePipeline (routing), Thing queries
Write: ProjectController (create/update/delete)
Indexes: tags (array), updatedAt (desc)
threadsknowledge store
Long-form conversation containers distilled by topic. Stores summaries, decisions, action items, evidence, extracted ideas. Supports many-to-many project linking and thread merging.
threadIdprojectIds[]titlesummarydecisions[]actions[]evidence[]extractedIdeas[]mergedFromThreadIds[]
Read: ThreadController, ExtractionService, DistillerService, ObjectiveService, MergeThreadsTool
Write: ThreadController, ExtractionService (ideas/actions), DistillerService (summaries), MergeThreadsTool
Compound: {projectIds, updatedAt desc} — project threads by recency

Thread Lifecycle

Created
Thread agent creates from intake content or merges from existing
Extracted
Thread-extractor pulls actions, ideas, tickets from messages
Distilled
Distiller compresses conversation into concise summaries
Merged
Duplicate threads merged — mergedFromThreadIds tracked
